# Figures

Manifest of the manuscript figures. Each is generated by
`code/07_figures/enabling_voices_figures_RSM.py`; the generating function and
data input(s) are listed below (paths relative to the repository root).

| File | Description | Function | Data input(s) |
|------|-------------|----------|---------------|
| `Fig1.png` | Llama 3.1 8B Round 1 confidence-score distribution by decision category (include / exclude / manual review) over the 461 records with a valid Round-1 decision. | `fig1_llama_confidence()` | `data/screening/enabling_voices_round1_V2_20260206_170842.xlsx` |
| `Fig2.png` | Areas of disagreement between Llama 3.1 8B and Qwen 2.5 7B in Round 1, by eligibility criterion (single-panel horizontal bar chart; n = 19 disagreement cases). | `fig2_disagreement_areas()` | `data/screening/model_comparison_report.xlsx` |
| `Fig3.png` | PRISMA-ScR flow diagram for the combined identification + LLM-assisted screening pipeline with human validation, ending in n = 6 included studies. | `fig3_prisma()` | none (static flow values) |
| `Fig4.png` | Retrospective agreement matrices (four panels): Llama 3.1 8B, Qwen 2.5 7B Round 1, and Qwen 2.5 7B Round 2 each against the adjudicated final-included set, plus a model-only Qwen Round 1 vs Llama panel. | `fig4_agreement_matrices()` | `data/screening/master_comparison.xlsx`, `data/screening/enabling_voices_qwen_v3_20260312_230707.xlsx` |

These are 600-dpi PNG copies of the generated figures; vector PDF versions for journal submission are produced by the same script (titles are omitted from the images by design — captions live in the manuscript).
